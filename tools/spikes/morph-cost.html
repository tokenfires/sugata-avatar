Spike 0.8 — morph-target cost on a 13.7k-vertex head

three.js packs morph targets into a DataArrayTexture, one layer per target, and walks every layer in a TSL Loop in the vertex stage. Cost is therefore O(vertices × targets) per frame. This page sweeps the target count across the shape budget we are actually considering — 52 ARKit + 15 OVR visemes + 2 gender = 69 — so the blendshape budget comes from a number rather than a hope.

Read the GPU column, not the wall column. Wall-frame time is vsync-locked and floors at the display refresh interval; it only becomes informative once a configuration is already over budget, and here it covers several passes per tick anyway. Δ vs 0 is the honest morph cost: it subtracts the fixed cost of the render pass itself.
