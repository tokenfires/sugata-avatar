# Reopenable Sugata clothing studies

These two Sage/lavender recipes preserve the accepted cut comparison: the same sage tee, navy denim, muted shoes and tinted hair, with either bob length. They use the current g050 body and stand-in clothes. Wider body fits and curated representative characters remain in progress.

| Cut | Settings file | Accepted original |
| --- | --- | --- |
| Chin-length bob | [sage-lavender-chin.json](sage-lavender-chin.json) | [Portrait and controls](../captures/wardrobe-hair-cut-2026-10-03-v1/desktop-before.png) |
| Long bob | [sage-lavender-long.json](sage-lavender-long.json) | [Portrait and controls](../captures/wardrobe-hair-cut-2026-10-03-v1/desktop-long-bob.png) |

1. With the local review server running, open the [Wardrobe study](http://127.0.0.1:5173/src/showcase.html).
2. Wait for the look to finish loading, choose **Open settings (JSON) ↑**, and select either file from this directory.
3. Use **Hair cut** to compare lengths, or edit the clothes and hair colours. Choose **Save settings (JSON)** to keep your version. **Save image (PNG)** captures the current avatar view.

Both files restore Studio with Neutral lighting, Portrait framing, balanced quality, the original pose/seed, and the same outfit, foundation and applied colours. Opening settings reloads the preview; camera orbit, motion clock and attention start fresh. The settings do not promise an identical rendered image. Neutral lighting is an inspection option, not colour calibration.

The long file preserves the actual downloaded and reopened JSON bytes. The chin file comes from the recorded initial configuration in the same accepted native run. Only the hair cut differs. These are the existing composition/control examples; hair finish, complete fit, movement and AAA character quality still need work. See the [accepted comparison](../docs/evidence/nonhair-2026-10-03/hair-cut/review.html) and [recipe/support receipt](../docs/evidence/nonhair-2026-10-03/representation-recipes/RECEIPT.md).

To try a brief camera-facing attention action with the chin-length look, follow the [attention viewing guide](VIEWING-ATTENTION.md). It covers **Resume motion → Look toward me → Release** with actual current samples. Attention remains a viewing action and is not stored in the recipe.
