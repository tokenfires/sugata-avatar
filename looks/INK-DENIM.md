# Ink and denim

An optional navy tee and denim composition with warm brown shoes, using the current g050 body and chin-length bob. It keeps the Brown hair setting without lavender tint. Both complete-look samples keep the tee/denim boundary and boots readable; Kitchen gives the outfit warmer, more shadowed light.

1. Open the [Wardrobe study](http://127.0.0.1:5173/src/showcase.html) with the local review server running.
2. Choose **Open settings (JSON) ↑** and select [ink-denim.json](ink-denim.json). It restores **Studio → Neutral → Full look**.
3. Switch to **Portrait** to inspect the face, or choose **Kitchen** to inspect the room lighting. To return to the first lighting context, choose **Studio**, then **Neutral**.
4. In Portrait, choose **Resume motion** if paused, **Look with a smile**, then **Release**. This uses the existing viewing action; it is not stored in the settings.

The file preserves the actual downloaded and reopened JSON bytes. Opening starts a fresh preview; camera orbit, clock and viewing action start fresh, so it does not promise identical images. Neutral is an inspection option, not colour calibration. The Brown hair setting reads ashier in Neutral and warmer in Kitchen; the darker hair edge is weaker against Kitchen's background.

The portraits still show coarse hair cards/stipple and jagged neckline edges. This is a supported clothing composition, not a finished character. These six contexts do not qualify other bodies, all angles, fit or continuous expression/movement. Release returns the action to idle; it does not restore the initial head pose. The captured smile change is subtle.
