# Isolated outfit-proposal preview

This local study exposes the catalogue chooser through explicit request and dismiss controls. It prepares the current tee, denim, shoes and default foundation in a fresh session, then keeps that outfit pinned while showing a suggestion. Independent image review is being collected before final retention.

[Open the local preview](http://127.0.0.1:5173/@fs/Users/robault/GitHub/sugata-avatar/docs/evidence/nonhair-2026-10-04/catalogue-proposal-ui/preview.html), press **Load sample preview**, choose a formality rating and press **Request suggestion**. **Dismiss suggestion** closes the card while keeping the preference in this session. Nothing applies the proposed clothing. At the reviewed1280×720 window, the lower card controls require panel scrolling.

The one trial requested4/5 and displayed **Blouse + skirt**, with its authored catalogue explanation. The actual rendered tee/denim/shoes and complete pinned state stayed unchanged. Dismiss removed the card, retained one unhonoured preference and returned focus to Request. The existing rig jaw/eye warning is recorded. These static controls establish no fit, motion, finished-character or full Dresser9.11 acceptance.
