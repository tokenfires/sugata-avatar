# Ari artist files

Unpack the whole `ari-artist-kit` folder together. The static `index.html` uses only relative files, with no script, server, external font or network dependency. Opening it in the reviewed browser still requires a separate actual file:// qualification; source and archive checks alone do not establish browser support. Each SVG/JSON and original reviewed image can also be opened directly from its named folder.

The original fictional concept is a raster discussion sheet. Its matte textured jacket differs from the original smoother padded-finish intent; the illustration leaves pleats/waist details indistinct and retains a tiny pale portrait-ear stud. It is not an editable or supported runtime character.

The four technical SVGs are the authoritative editable art. Work on a copy, edit named groups/elements and refresh the accompanying JSON associations after edits. The JSON files preserve their original editing registries and limits; importing these into an unspecified editor has not been tested. The images named original-first.jpg, second.jpg and first.jpg are the unchanged previously reviewed captures, rather than new captures of this package.

- `bomber/`: exterior front/right profile/rear, original front-panel inside schematic, zipper/facing/hem details. Sleeve/rear lining was omitted from that older schematic; the separate interior study supplies its own additional intent.
- `interior/`: lining, facings, back, both sleeve linings, neck/fold and hidden bags. Inside studies put wearer R at image-left, including the independently drawn inside-back. Labels are not matched cut edges. Access stays on the two outer pockets, with no new inside pocket.
- `trousers/`: independent front/right profile/rear, front band, outward pleats, fly/guard, pocket layers and hems. Only the right bag has a complete drawn contour; left is written counterpart intent. Light detail fills explain layers rather than garment color changes.
- `shoe/`: one left shoe's six independent views plus entry/lacing detail. Five eyelet pairs belong to the top; the enlarged detail shows three central pairs. Right counterpart is written intent only. No rejected 3D shoe is included.

These are unitless, independently authored views, not registered projections, measured patterns or a reconstruction from photographs. Physical sewing/topology, lining continuity, closure/access mechanisms, material behavior, measured dimensions/ease, anatomical pairing, body/foundation/foot fit, rig/morph/pose/motion, representative performance, runtime and complete-character/AAA quality remain open. Packaging changes none of those qualifications.

MANIFEST.json lists the exact copied file identities and their source locations at the retained repository epoch. Its own identity is intentionally excluded from its member-hash list to avoid a recursive hash. Gallery and editing-note hashes are listed separately from the thirteen unchanged artwork/data payloads. The interior JSON retains a historical absolute bomber-SVG path; historical_path_mappings explicitly maps that source to `bomber/bomber.svg`. Those strings are provenance, not active gallery dependencies, and were not rewritten.

This bundle does not include commercial reference photos, complete repository evidence trees, 3D models, patterns, an importer or a runtime. Consult the original repository handoffs for the independent review history. The manifest's source locations are historical provenance, not a promise those locations exist on another machine.
