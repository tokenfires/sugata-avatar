## 4. Concrete finite joint projection

This is a static Jacobi constraint-authoring method, not the paper's Gauss-Seidel dynamic simulator, physical knit simulation or a global-minimum algorithm. No velocity, gravity, time integration, friction, pressure, tearing or self-collision response is included. Full final embedding rejects self-contact instead of pretending the projections prevent it.

Use exactly3 stages of8 sweeps each. Target gains are0.005,0.01,0.02; edge gain0.25, differential-coordinate gain0.10 and contact gain0.90 in all stages. Each sweep reads one frozen current P and computes **all** constraints from it. Accumulate individual correction vectors and a count per affected free vertex; then update each free vertex by0.5*sum(corrections)/max(1,count). Clamp that vertex's final step norm to0.005m. Fixed positions remain exact copies. Rebuild current triangle normals/AABBs/BVH and all contact constraints every sweep. No contact set is frozen across sweeps; no adaptive gain, constraint-order search, line search or rerun.

For a scalar constraint C with frozen per-vertex gradient g_i and inverse weights w_i, D=sum(w_i*dot(g_i,g_i)). Equality corrections are -gain*C*w_i*g_i/D. Inequalities use that correction only for C<0. If a violated constraint has D=0, refuse with exact affected fixed IDs/operands; if D=0 and C=0 it contributes nothing. Nonfinite C,gradient,correction or D refuses. Compute constraints in family order below, then IDs ascending; accumulation uses that order.

1. Artist attraction: for each free vertex and coordinate alpha, C=P_i,alpha-T_i,alpha, gradient1 for that coordinate. Fixed positions are not attracted. This defines positional intent, not measured anatomy.
2. Edge lengths: for every unique triangulated physical edge sorted endpoint IDs, C=norm(P_i-P_j)-norm(T_i-T_j), gradients n and -n with n=(P_i-P_j)/currentLength. Zero current or target length refuses.
3. Differential coordinates: for every vertex, neighbors are all unique triangulated-edge neighbors in ID order, d their count and L0=T_i-mean(T_neighbors). For each coordinate C=P_i-mean(P_neighbors)-L0, gradients1 at i and-1/d at each neighbor for that coordinate. Fixed vertices participate with weight0. This is explicit regularization, not an unspecified bending model.
4. Required-source contact: process **every corner occurrence** of every required fan triangle, retaining owner/original/fan/corner provenance (duplicates intentionally remain). Find closest point c on current physical triangles, with its barycentrics beta and oriented unit face normal n. Exact tie in binary64 squared distance chooses smallest physical face ID; closest-feature ties choose face,then edge01/12/20,then vertex0/1/2. The frozen-normal surrogate is C=dot(n,c-q)-0.015. Its frozen gradients at the face's vertices are beta_i*n. This is an approximate signed local guide; it neither classifies the whole source nor certifies continuous clearance. Ambiguous inside/outside closest-normal behavior is left to independent acceptance, never used to choose a favourable final side.
5. Whole-source two-sided near contact: every original world point of all9 owners in original ID order, without welding, gets its closest c and distance d. Only if d<0.015, use C=d-0.015 and frozen gradients beta_i*(c-q)/d. Zero d refuses with witness. This guide includes exposed points; it does not force exposed head/hands/lower body inside temporary caps. It is still a point guide; all original triangles receive separate continuous acceptance.

All closest-point searches use all physical triangles via a median BVH with leaf8. Split longest AABB extent, axis ties X/Y/Z; stable centroid coordinate/face-ID order; exact leaf computations are binary64 point/triangle feature candidates. Visit children by AABB distance then stable node ID. Prune only when AABB squared distance exceeds current best plus1e-12m²; this conservatism is solver-only, not an acceptance certificate. Refuse above200,000 required corner occurrences,50,000 original points,2,000 vertices,4,000 triangles or20million total solver leaf-triangle evaluations across all24 sweeps.

The surrogate diagnostic objective is sum(gain*C²) over equalities plus sum(gain*min(0,C)²) over current inequalities. Record each family's value, maximum residual, correction counts, largest step and contact identity/count per sweep. The Jacobi average/clamp does not promise descent or convergence. Always finish24 sweeps unless a declared failure/resource limit occurs; no early favourable stopping. Save final complete arrays before independent acceptance.

Caps have separate IDs and **never** enter physical geometry, physical clearance, export or rendering. Verify the capped surface is oriented, connected and closed, positive exact signed volume and all vertex links cycles.

Physical/cap embedding: test every triangle pair with touching-inclusive AABB overlap. For adjacent triangles, allowed intersection is exactly the declared common vertex/edge; no extra overlap. Nonadjacent pairs must be disjoint. For noncoplanar triangles, exact signed plane tests and segment-plane intersections clipped by exact barycentric signs yield the complete intersection segment/point set. For coplanar pairs, project by largest normal component, axis ties X/Y/Z; exact2D segment intersection (including collinear overlap endpoints) plus mutual vertex containment yields all intersection-polygon points. Their convex hull must be contained in the declared common simplex or be empty as appropriate. A shared-index pair is not exempt from crossing tests. No floating normal heuristic may waive contact.

Continuous gap: for every entire original positive-area triangle and every required fan triangle, certify distance from the entire physical garment >=0.010m. For a triangle pair, first test exact intersection; an intersection has zero gap. Otherwise compute the minimum of six point/triangle squared distances and nine segment/segment squared distances. Point/triangle candidates are its unconstrained plane projection if all exact barycentrics>=0, plus each edge's clamped closest point; singular triangles refuse. Segment/segment candidates include all four endpoint/other-segment projections and the unconstrained two-parameter solution if its Gram determinant>0 and parameters in[0,1]. For parallel segments the endpoint candidates cover the minimum; zero-length source edges are handled by point/segment candidates without dividing by zero. Compare exact rational squared distance against1/10000m²; equality passes. This includes triangle interiors and edges, never merely original vertices.

An acceptance BVH contains complete exact rational triangle AABBs. Source triangle/AABB distance may certify a pair or subtree only when its **exact** minimum squared box distance is already>=1/10000. Remaining leaf pairs receive complete exact distance/intersection tests; record all evaluated/pruned counts, per-source full-domain threshold certificate or first exact failing pair and operands. A threshold certificate is not an observed global nearest distance.

For required inside classification, each positive required fan triangle gets its exact rational centroid as an interior representative. Its full fan triangle is already disjoint from every physical face by gap acceptance. Its corners must also lie at least0.015m inside each shifted cap plane, separately allowing only1e-12m recorded source/cap reconstruction residual. All exact forward ray/triangle intersections with the complete capped surface must be counted. A ray on a face plane, hitting a vertex/edge, or an origin on any boundary is ambiguous and refuses; no perturbation, majority fallback or direction search. Require all three counts odd for every fan triangle. This checks every connected domain piece, not a chosen centroid without disjointness. No body-solid/orientation assumption enters this test.
