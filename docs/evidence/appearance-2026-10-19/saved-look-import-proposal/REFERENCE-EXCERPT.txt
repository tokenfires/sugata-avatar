1203: ##### 6.2.3.2. The `readAsText()` method
1204: 
1205: The `readAsText(blob, encoding)` method,
1206: when invoked, must initiate a [read operation](https://www.w3.org/TR/FileAPI/#readOperation) for blob with _Text_ and encoding.
1207: 
1208: ##### 6.2.3.3. The `readAsArrayBuffer()`
1209: 
1210: The `readAsArrayBuffer(blob)` method,
1211: when invoked, must initiate a [read operation](https://www.w3.org/TR/FileAPI/#readOperation) for blob with _ArrayBuffer_.
1212: 
1213: ##### 6.2.3.4. The `readAsBinaryString()` method
1214: 
1215: The `readAsBinaryString(blob)` method,
1216: when invoked, must initiate a [read operation](https://www.w3.org/TR/FileAPI/#readOperation) for blob with _BinaryString_.
1217: 
1218: Note: The use of `readAsArrayBuffer()` is preferred over
1219: `readAsBinaryString()`, which is provided for backwards
1220: compatibility.
1221: 
1222: ##### 6.2.3.5. The `abort()` method
1223: 
1224: When the `abort()` method is called,
1225: the user agent must run the steps below:
1226: 
1227: 1. If [this](https://webidl.spec.whatwg.org/#this)’s [state](https://www.w3.org/TR/FileAPI/#filereader-state) is `"empty"`
1228:     or if [this](https://webidl.spec.whatwg.org/#this)’s [state](https://www.w3.org/TR/FileAPI/#filereader-state) is `"done"`
1229:     set [this](https://webidl.spec.whatwg.org/#this)’s [result](https://www.w3.org/TR/FileAPI/#filereader-result) to `null`
1230:     and [terminate this algorithm](https://www.w3.org/TR/FileAPI/#terminate-an-algorithm).
1231: 
1232: 2. If [this](https://webidl.spec.whatwg.org/#this)’s [state](https://www.w3.org/TR/FileAPI/#filereader-state) is `"loading"`
1233:     set [this](https://webidl.spec.whatwg.org/#this)’s [state](https://www.w3.org/TR/FileAPI/#filereader-state) to `"done"`
1234:     and set [this](https://webidl.spec.whatwg.org/#this)’s [result](https://www.w3.org/TR/FileAPI/#filereader-result) to `null`.
1235: 
1236: 3. If there are any [tasks](https://html.spec.whatwg.org/multipage/webappapis.html#concept-task) from [this](https://webidl.spec.whatwg.org/#this)
1237:     on the [file reading task source](https://www.w3.org/TR/FileAPI/#fileReadingTaskSource) in an affiliated [task queue](https://html.spec.whatwg.org/multipage/webappapis.html#queue-a-task),
1238:     then remove those [tasks](https://html.spec.whatwg.org/multipage/webappapis.html#concept-task) from that task queue.
1239: 
1240: 4. [Terminate the algorithm](https://www.w3.org/TR/FileAPI/#terminate-an-algorithm) for the [read method](https://www.w3.org/TR/FileAPI/#read-method) being processed.
1241: 
1242: 5. [Fire a progress event](https://www.w3.org/TR/FileAPI/#fire-a-progress-event) called `abort` at [this](https://webidl.spec.whatwg.org/#this).
1243: 
1244: 6. If [this](https://webidl.spec.whatwg.org/#this)’s [state](https://www.w3.org/TR/FileAPI/#filereader-state) is not `"loading"`,
1245:     [fire a progress event](https://www.w3.org/TR/FileAPI/#fire-a-progress-event) called `loadend` at [this](https://webidl.spec.whatwg.org/#this).
1246:
