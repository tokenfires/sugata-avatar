# Proposed rest-frame TRS helper contract

Nomination only, no serializer/GLB/consumer or motion acceptance. Direct matrix-bearing named joints are not selected: primary spec831–845 restricts matrix decomposability/affine properties;3043–3051 prohibits TRS animation channels on nodes with matrix. This does not establish that the measured tiny residual is inherent shear or that every static matrix is forbidden. Current Three loader4372–4376/applyMatrix4 and Object3D448–456/1165–1167 decompose then ordinarily recompose matrix transforms; exact raw preservation is unproven under that path.

For each of53 named native joints, derive raw desired glTF world G=C*rig.world*bone.rest from frozen inputs. Desired raw local M=parentG^-1*G, with the existing rig object frame for roots. Keep source model/rest values unchanged. One pure-data SVD of M3x3 gives U*diag(s)*Vt. Adjust signs so U/Vt are proper rotations, carrying any sign in scales; require finite nonsingular factors and unit quaternion representations.

Declare TWO static TRS helper nodes per joint: H1 carries local translation, U rotation and diagonal scale; H2 carries Vt rotation with zero translation/unit scale. The named joint J has identity rest TRS. Explicit path is native parent joint(or rig)->H1->H2->J. J's children become each native child H1. Exactly106 helpers are uniquely identified, excluded from skin.joints and from native bone identities. Exactly53 J names/joint order/IBM ownership remain. Native nearest joint ancestor is preserved; immediate graph parent changes by the two declared helpers. Total166nodes includes7 original owners. No hidden extra joint/leaf bone or count-only rescue.

Require H1*H2*J matches each raw local at1e-6 and all53 composed J worlds match raw desired worlds at1e-6. Bind matrices remain associated with named J, inverse of raw G in the declared frame; source positive skin/geometry/morph/default/primitive/UV/material responsibilities remain. Helpers are ordinary non-joint transform nodes, allowed by primary node hierarchy/skin.joints semantics. Installed Three marks Bone only from skin.joints and traverses generic child nodes; Figure builds named bone index by isBone. These are source leads, not actual consumer acceptance.

Animation responsibility: helpers remain static. Identity-rest J offers explicit TRS channels; a post-rest local delta yields M*delta. No claim that this equals every native constraint/inherit-scale/pose convention, existing procedural motion, retargeting or runtime performance. Those need a future explicit mapping and real consumer/motion qualification. Wider expression/wardrobe/representation roadmap stays open.

A one-pass PURE-DATA53-factor feasibility check may use NumPy SVD and the pinned current Three Quaternion/Matrix4 math to reconstruct the declared TRS values and worlds. No Bone/Object3D/rig, model load, exporter, renderer, point inventory or production edit. Record all inputs/factors/quaternions/helpers/reconstruction/errors/sign rules and refuse any unsupported/singular/nonfinite case. No repeated factorization/tolerance adjustment after outcome.
