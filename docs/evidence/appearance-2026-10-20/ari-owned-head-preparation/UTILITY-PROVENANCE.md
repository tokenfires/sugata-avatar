# Utility and source provenance

The actual apply_patch authoring in this session created head.py (geometry plus software renderer/export) and run-once.py (supervisor) from zero. No prior head/curl/boot/garment producer, mesh, helper, observer or guard was imported, copied, run or modified. Shared elementary ideas—vector operations, section interpolation, Gaussian relief, triangle barycentric rasterization, PNG chunks, process/fuse/hash/timeout handling—are utility techniques, explicitly reauthored here. Their appearance in earlier work does not make its failed source a new ingredient. This is no renamed curl/scalp/garment acquisition or loft-control experiment. All literal new facial source/feature/opening/attachment obligations are in DESIGN/CONTRACT and the complete new programs. New method quality remains unknown until the first actual mesh/image, if separately admitted. Imported modules are Python standard library only; AST parsing never imports/evaluates these programs. Runtime pinning covers the exact executable and version, not a complete OS/dynamic-library/stdlib reproducible environment.
