That direction is diagnostic evidence; it is not a proven correction.

The candidate's largest root-edge departure is at frame210/downward20° pitch. The critic independently found the root midpoint stable to 0.0001274 mm and width stable to 0.0000889 mm across the samples. The edge departure reflects ribbon rotation, not a detached root. No corresponding rendered crease has been established. Changing the root frame merely to improve this statistic is not justified by the current images.

The crossing instrument queries the selected32GPU triangles against the same frame's fully morphed/skinned body with unbounded spatial limits. Signed vertex distances use matching skinned/morphed normals. It excludes garments, hair-hair contact and time between samples. Zero shell crossings would not rule out a wholly internal triangle; signed vertices support but cannot prove positive clearance everywhere. Neither fewer crossings nor a low final tip lag is a motion acceptance gate.
