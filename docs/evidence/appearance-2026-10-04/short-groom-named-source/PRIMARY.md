Snow is a character rig you can use to learn and practice your animation skills, created by us here at the Blender Studio.

If you encounter any bugs, please report them [here](https://projects.blender.org/studio/blender-studio-pipeline/issues/new?template=.gitea%2fissue_template%2fcharacter_rig_bug.yaml).

Originally made in 2022, he's now been updated to work with Blender 4.1 and beyond.

When opening the file, you may be prompted to allow execution of Python scripts. This is necessary for the custom rig UI, which houses the following features you may be used to from our rigs:

- IK/FK toggle and snapping for the limbs
- Stretchy IK toggle for the limbs and spine
- FK Hinge toggles and snapping
- IK Parent switching and snapping
- Layered face controls with shape key correctives
- Designed with newcomers and pros both in mind
- No add-ons required! All required scripts are included with the .blend and will auto-run when opening the file.

The rig is free to use, provided that the you respect the CC-BY license and include the credit: Snow Rig (CC) Blender Foundation \| studio.blender.org
