# Proposed one-export association predicates

This is a source-qualified proposal for instrument preflight, not permission to run an exporter. OPTIONS-PROPOSED carries32 literal options. Registered RNA/value support, instrument limits and first-output guards must be verified under a later execution contract.

**Native input/control.** Load only exact7493efbb… candidate, cold owner/map/expanded-key signature and all six raw influence arrays bound to98e018c7… census. Exactly six meshes/Human.rig. Require finite source coordinates/UV/weights/transforms, the measured cutoff absence, positive complete bone sums, unique native owner names/bone names and supported modifier/relative-key states. Reject unexpected muted/non-Basis-relative/vertex-group-masked/animated shape semantics rather than silently exporting a subset. Source-only slider ranges/interpolation UI are preserved in sidecar metadata; no automatic glTF UI equivalence.

**Selection/identity.** Select only those seven native owners. Add three fresh underscore diagnostic attributes to each working mesh, never the saved input: FLOAT point vertex index, FLOAT corner loop index and FLOAT face polygon index. IDs are finite exact integers below2**24 with no name collision. Installed extractor accepts POINT/CORNER/FACE and uppercases names; INT is converted toFLOAT. Explicit FLOAT avoids signed-type ambiguity. Existing unprefixed source provenance does not suffice. Corner IDs deliberately force splitting, so this audit GLB is not a production/performance nomination.

**Topology/UV.** Capture native calc_loop_triangles ordered corner triples and material slot index before export. Decode actual GLB header/chunks/accessors, offsets/strides, sparse replacement and component/normalization types, refusing external/unsupported references. Each indexed output triangle's diagnostic corners/face/point values must map to one exact native triangle/material owner; permit only cyclic rotation preserving winding, no nearest or count-only rescue. Require exact winding-aware multiset equality of the COMPLETE native and output `(owner, material-slot identity, source-face ID, cyclic corner-ID triple)` records, preserving multiplicities in both directions. This prohibits missing or duplicated triangles; one-way per-output membership is insufficient. Every referenced output vertex maps to the stated native point and loop. Compare UV to `(u,1-v)` at1e-6; each material texture's declared texCoord/transform must reference the corresponding native loop UV responsibility. Source extractor393–419 buckets triangles by material;1377–1434 dispatches native domains into loop dots;932–941 deduplicates those dots.

**Positions/morph/defaults.** For skinned meshes, extractor1122–1159 forms base/shape positions in object-world space then swizzles `S(x,y,z)=(x,z,-y)` and forms deltas. Compare POSITION against that declared base, and every morph delta against `S(Mworld*key-Mworld*relativeBase)`, finite/1e-6m. Capture Base/name/order/default value for every eligible key using the exact get_sk_exported exclusions: first/Basis, self-relative and muted are skipped (data_path61–80). Future input guards must own those exclusions, not claim all98 become targets. `obj_data119–123` writes targetNames;154–175 writes active key values as mesh.weights. Node weights areNone in nodes556–557. Require exact eligible names/count/order and effective mesh/node default vector against current source values, including eight active body macros. The no-animation reset branch is not a zero-default guarantee. Reconstruct default positions from actual encoded base/deltas/effective weights and compare to native default visible positions under the declared frame; no native appearance/motion acceptance from arithmetic alone.

**Skin/joints/binds.** Explicit all-influences=True, no deform-only filter, no leaf bones, no armature removal or hierarchy flattening; rest-armature=True/current-frame=True. Require actual skin.joints mapped one-to-one to all53 named native bones and native parent ancestry, with no extra neutral/leaf or missing bone. Tree575–591 traverses exported children, while skins uses that same ordering for IBM/joints; indices may differ from native array order and must be resolved by identity. For each actual output point, validate every JOINTS_n/WEIGHTS_n slot: joint index must resolve in the skin, and weight must be finite and nonnegative. Permit and record zero-weight VEC4 padding; duplicate zero-weight joint indices do not add an influence. Reject duplicate positive contributions to one joint identity. Compare the complete positive joint set and normalized native bone weights (raw/sum) within1e-6, with no missing or extra positive influence. Source primitive_extract1593–1594 rounds the number of sets up to groups of four; primitive_attributes92–131 reshapes weight/joint arrays by four. Source normalization is float32; record absolute residuals, do not treat raw nonunit sums as identical encoded values. This is not a posed-motion test.

Skins73–136 declares each column-major IBM as inverse of `C*(rig.world*bone.rest)`, with C the literal x/z/-y4×4 basis. Compare each named matrix within1e-6. Joint local transforms must follow the actually read tree310–326/joints40–67 rest/parent decomposition and swizzle sequence, not an invented shortcut; materialized encoded scene hierarchy and skin-rest action must be independently checked. If that exact replay cannot be authored consistently, stop before export. Names/identity matrices alone are insufficient and old g050 rig evidence is not borrowed.

**Materials/images and explicit holds.** Preserve native material-slot/primitive ownership and named exported materials, alpha modes/cutoffs/double-sided/base color/metallic/roughness/texture bindings as a declared glTF representation; native arbitrary shader graph/SSS/fine-eye equality is not representable by a simple property-name match and remains held. Materials97–158/pbr22–51 assemble socket-derived PBR/alpha/texture/extension fields. Image119–129 embeds encoded bytes for GLB; encode_image218–244 may compose channels. Its384–411 fast path reuses packed clean FILE bytes only when MIME matches; otherwise a temporary image is encoded. Thus six packed native images do not guarantee six identical GLB images. A future input/material gate must identify direct image/socket/channel/UV routing versus composition, and require either exact direct packed bytes or an explicitly authored channel/factor association. Unknown routing/composition, omitted texture or unsupported extension stops this full association; do not silently declare native shader equivalence. AUTO preserves eligible existing format; no JPEG/WebP nomination or new image edits.

**Completion/preservation.** Fresh isolated GLB only; FINISHED/new file plus actual parsing required. Capture and compare every original owner/provenance/key/weight/material/image record before/after while accounting only for three named diagnostic attributes. Physically rehash candidate and pristine source; never save either. Preserve a failed/partial first GLB and raw report; no repeated export, source/vendored weight or threshold adjustment. Actual GLB images/expression/motion are later obligations.

**Current decision.** The proposed geometry/morph/skin/identity predicates and literal options are concrete, but the exact joint-local replay and actual native material socket/channel routing are not yet implemented or candidate-qualified. Full-policy export admission remains held at those responsibilities. Next preflight work must either own them in one bounded instrument or narrow a separately declared numeric-only format contract; it cannot pretend full shader/image equivalence. No native/GLB or new source/candidate manipulation occurs in this source slice.
