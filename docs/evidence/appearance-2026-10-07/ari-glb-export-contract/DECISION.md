# Stop full skin-preservation admission at the weight cutoff

The stock exporter cannot be assumed to carry every positive native joint weight merely by setting `export_all_influences=True`. Installed `primitive_extract.py:1560–1588` sets `min_influence=0.0001` and skips weights `<=` that value before each per-influence joint lookup (the group-to-joint table is already constructed). Separately, `primitive_attributes.py:68–90` preserves every gathered VEC4 set only when all-influences is enabled; otherwise it caps the sets, then149–171 normalizes the weights that remain. This is actual source behavior, not an observed loss in this candidate.

The current15-keyword builder wrapper omits all-influences, and addon `__init__.py:925–937` defaults to four influences with all=False. A later candidate call must explicitly set all=True to avoid that cap; this alone does not remove the earlier hard cutoff. No vendor threshold, weights or accepted builder are edited.

**First missing responsibility:** the cold candidate's recorded receipts hash native influence arrays but do not enumerate their raw bone weights. This source-only inquiry cannot establish whether any candidate body/face owner has a positive mapped-bone weight at/below0.0001, a zero/nonfinite/negative bone sum, or an unexpected joint mapping. Full native-influence preservation therefore remains unadmitted. Source text is not candidate eligibility or a universal exporter incapability proof.

A — next preferred: one separately preflighted read-only candidate skin eligibility query, limited to each mesh's actual native armature/modifier/vertex-group-to-bone association, every positive joint weight, per-vertex sums and the exact cutoff participants. No source/weight changes, pose experiment or GLB. If no native weights would be removed, the stock path may be eligible for a later complete association test, comparing normalized exported weights to the complete normalized native set. If any would be removed, retain exact owner/vertex/bone/weight witnesses and stop stock full-preservation admission. This costs one bounded native read and separates actual input from hypothetical loss. Native bone membership does not by itself qualify the eventual exporter joint tree, inverse binds, defaults or materials.

This avoids its cutoff but adds a substantially broader encoder/joint/bind/material responsibility and needs separate source, numerical and visual qualification. Accepting an explicitly lossy conversion would likewise require a new measured motion/visual contract; neither tuning weights nor relaxing the current preservation claim is supported.
