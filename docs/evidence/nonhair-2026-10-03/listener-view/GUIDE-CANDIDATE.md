# Try the attention view

Draft awaiting current native sequence review.

1. Open the [Wardrobe study](http://127.0.0.1:5173/src/showcase.html), choose **Open settings (JSON) ↑**, and select `looks/sage-lavender-chin.json`.
2. Wait for the look to load. It opens in Portrait with the Sage/lavender colours and Neutral Studio light.
3. Scroll to **Attention · experimental**. If the page says **Resume motion to try attention**, choose **Resume motion** first.
4. Choose **Look toward me** for a brief neutral attention action toward the current camera. Keep the front view while trying it.
5. Choose **Release** while the action is active to return to ordinary motion. It also eases out automatically after a few seconds. Turning the view or pausing motion ends the action.

Saved settings restore the look; attention starts fresh each time. This is an experimental viewing action. The current hair, fit and expressive character work remain in progress.
