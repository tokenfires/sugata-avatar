## Interpretation and next design

The raw case names `base-full-blink` and `height2-full-blink` mean **morph coefficient 1 in this pilot**, not the runtime full-blink command. Current `Blink.js:267` uses 0.752. `ocular.selftest.mjs:1378` already implements a frontal triangle-depth baseline lid-seal test including both globe and cornea. This pilot neither invents that baseline method nor contradicts its calibration. The corrected README makes this distinction explicit.

The useful continuation is a separately designed identity-aware comparison with that existing baseline instrument. It should first align and record (1) actual coefficient/command semantics, (2) globe plus cornea membership, (3) transforms and rest-versus-skinned space, (4) culling conventions—existing `depthMap` admits either winding whereas this pilot honors front-sided materials—and (5) sample grid and triangle selection. Existing `eyePatch` selects triangles from the undeformed baseline neighborhood, so an identity extension must prove that selection still contains every relevant deformed triangle or use complete geometry. No silent normalization of these differences is appropriate.

Zero samples at coefficient 1 do not prove continuous seal: sub-grid openings, oblique views, lid foldover/intersection and incorrect proxy fitting remain possible. The reported column span includes the first-to-last visible sample even if disconnected, so it is not a continuous local eyelid gap. The area is a finite-grid estimate without a convergence/error bound. The historical named red case has not been established; do not force one or mark PUNCHLIST 10.3 complete.

Two bounded later options are an extension of the existing baseline gate using the actual 0.752 coefficient and both shells (best calibration continuity, requires explicit convention alignment), or a standalone identity-aware full-mesh ray oracle at the same declared state (clearer geometric isolation, still requires independent native visual/fit checks). Neither requires a corrective or changing an accepted asset before a defect is proved.
