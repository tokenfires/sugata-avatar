Why this run is retained

Two60-update warmup windows had the same native pipeline, resource and pass census; every sample preserved it. All8,240 render/compute pass queries were fresh and accounted. All420 same-browser camera/control predictions matched exactly. The six diagnosed warnings occurred before instrumentation; no later warnings or errors occurred. Sources stayed fixed and both query pools retired cleanly.

This remains one headless Chromium run of one body and outfit. Other applications were not controlled, and stepping changes queue pressure and idle time. It does not establish live responsiveness, representative-avatar readiness, fit or hair quality. Keep this baseline; investigate live cadence only if a concrete responsiveness problem warrants it.
