The critic identified five admission gaps. These are instrumentation repairs, without changing the candidate, native state, trace, images, or acceptance thresholds:

The raw input archive keeps both. `stableInputProjection` validates finite nonnegative values, then removes exactly those two paths from a copied comparison object. That fixture is timing evidence, not a nose-capture ready result.
2. **Startup must match the intended protocol independently of the control arm.** The literal exported configuration, attached native identity/hair/scene/wardrobe report, six loaded GLB bodies and exact hashes are now required. Missing, duplicate or unexpected GLBs fail. Every fresh page must perform exactly one native HTML transform matching the original source and requested URL.
3. **Shutdown precedes completed admission.** Every native owner retirement is attempted once. Context, browser and server each get a separately bounded, recorded close attempt; failure of one does not prevent attempting the others. A timeout fails admission and does not claim termination. The final source/manifest check and response/error drain run after these closes. No seal is written on failure; the original capture error remains separate from cleanup or final-check errors.
4. **Failure steps distinguish attempted from retained work.** `attemptedLoopStep` is assigned before calling the native step/readback. `lastRetainedSemanticStep` is assigned only after archiving the returned state. No recovery update or draw is introduced.
5. **Dataset admission is separate from face qualification.** The report explicitly names `ownershipReconstructionAdmission`, with a narrowly scoped `numericalAdmission` alias. Full body/proxy data is retained for that separate analysis; a correct reconstruction alone does not establish clearance.
