## Posed contacts: smallest complete scope

Use the union of the operator's recorded affected faces at −1/+1: every triangle incident to a changed body position, including boundary faces. This is 184 source body triangles at the admitted rest inputs, not a weight threshold or a hand-selected nasal patch. The same IDs are used at every saved native pose.

For each arm and saved pose, test that union against:

1. **Every body triangle.** Preserve source-index weld identity; a genuine shared source vertex/edge is an attachment, while overlap beyond that actual shared simplex is a contact witness. Never drop every adjacent face. Confirm that supposed welded vertices are still equal in the supplied posed coordinates before applying a shared-simplex exclusion.
2. **Every triangle of all six face proxies.** Separate globe, cornea, teeth, tongue, brows and lashes in the report. Distinct meshes have no body-topology attachment exemption, even if coordinates coincide.
3. **Every worn mesh triangle**, with full and drawn results separately. This is cheap locality screening with the same complete target surfaces, not a new fit analysis or a mask change. Native groom particle/card physical state is retained, but the geometry snapshot is not a posed hair-triangle archive: do not claim full groom surface clearance from it.

Use the existing floating contact kernel only as a numerical witness finder with its declared 1e−9 m policy. Adapt the independently reviewed exact-rational plane-section/coplanar kernel in `verify-local-geometry.py` into a separately bound analyzer for the supplied Float32 snapshot coordinates. Closed AABB rejection supplies candidate pairs; exact coordinates determine contact. For body pairs, retain the precise shared-source-simplex rule. For different meshes, source namespaces are disjoint. The current endpoint CLI asserts zero contacts and is therefore **not** directly suitable for classifying pre-existing posed contacts; leave it frozen and keep the new read-only wrapper explicit.

Report all baseline/pristine contacts, zero parity and candidate changes: retained, newly introduced and removed pairs, with mesh/face/source-index IDs and exact supplied vertices. No baseline contact is silently deleted. Independently verify any new witness and all borderline floating/exact disagreements. Also check finite coordinates, nonzero triangle area, and the candidate/pristine oriented-normal dot at the **same native pose**, using exact rational signs for the affected faces. A positive dot rejects reversals relative to that posed baseline; it is not an aesthetic shape test.

No invented positive clearance margin is proposed. If AABB bounds give a positive conservative separation from a proxy, retain the numeric lower bound and its scope; a failed conservative bound is merely inconclusive. Zero triangle intersections do not establish a signed outside classification, exclude containment, prove good lip/lid apposition, or qualify a continuous parameter/motion range. Stop and classify a new contact or a degenerate/reversed face before any wider proposal. Do not parameter-search within this analyzer.

## Native aperture: reuse the calibrated instrument, keep ownership explicit

The existing `identity-closure-next/aperture-calibrated.mjs` and its independent `critic-calibrated-oracle.mjs` agree on all sixteen source-rest masks, with analytic front/rear/window/winding controls. Their red eye-height case uses an **isolated** blink coefficient 0.752 and unfitted proxies. That report is calibration evidence; it is not this native avatar's composed state.

For the new dataset, initially analyze only retained step 0 and the actual first complete perceptual blink in all four arms. Use the saved posed body, opaque globe and corneal-shell triangles directly. Read actual committed `eyeBlinkLeft/Right` and all other ocular channels from that matching native state. Do not replace the composed geometry with a hand-added 0.752 morph or a nearest-vertex/spherical-shell estimate.

Use one declared frontal ray basis from the **saved native camera** for each matched step, preserving metric units from the world-coordinate data. Record its basis/scale checks and derive grid bounds from the union of the actual globe and cornea, with the already reviewed 0.1 mm pitch and 1 mm padding. All arms at that step share the same rays and exact proxy geometry. Preserve actual source material sidedness plus the existing both-windings comparison. Keep opaque-globe exposure separate from transmissive corneal-shell geometry.

Run both the projected triangle-depth kernel and the independent 3D ray/triangle implementation on that same posed input. Retain binary masks, exact sample positions, nearest surface face IDs, changed rays and per-eye sample counts/areas/column spans. Cross-arm exact mask equality is a useful **non-regression observation**; do not force a zero mask if the real composed baseline has exposure. A mismatch gets a real triangle/ray witness rather than a relaxed edge tolerance. The moved tip is outside the source eye-morph support, but that alone does not replace this occlusion comparison.

The finite grid cannot prove a continuous seal, minimum gap, absence of lid overlap or complete visual correctness. The six remaining declared expression/speech plates can receive the same analysis only if a concrete aperture difference calls for it; no broad motion matrix is planned. Root/critic must review the input-frame adaptation before executing it.
