# Proposed local normal transport and CPU admission

This is a source-owned diagnostic for **one** existing nose-tip-width target, at the authored source endpoints −1, 0 and +1. Those values are not an aesthetic range or a product option. Root owns subsequent native qualification. There is no asset export, Avatar API change or per-frame writer.

[normal-audit-v1.json](normal-audit-v1.json), generated by [normal-audit.py](normal-audit.py), establishes the current normal ownership. All 1,122 source-index split groups in the body have exactly equal authored normal vectors. Neither tip endpoint's normal neighborhood contains any split positions. The decrease end moves 64 positions and requires 114 normal positions, whose complete weld neighborhoods include 276 faces; increase moves 42 and requires 83 normals across 214 complete faces. The authored normals are not simply area-weighted normals: their maximum difference in these neighborhoods is 4.3133665° / 3.6233317°.

## Chosen hypothesis

Use the existing verified **source index** map, never proximity welding. Determine changed faces from the complete body index buffer. Every source weld incident to a changed face is normal-affected. For each such weld, sum cross products over **all** its original incident faces once, including unchanged adjacent faces. Compute the same sums from the displaced Float32 positions. Normalize those sums to `g0` and `g1`.

Take the shortest rotation from `g0` to `g1` and apply it to each **pristine authored** normal in that weld. Preserve its original length; do not normalize the authored normal to a different unit length. Round output components once to Float32. This retains the authored angular offset relative to the local geometric normal. It does not claim to recreate Blender's authored shading on a different shape.

All other normal bytes remain exact. Weight zero returns an exact copy of the original GLB, bypassing position and normal arithmetic entirely. Each endpoint is generated independently from pristine bytes; no sequential deltas, subtract-to-reset or accumulated reshaping.

**Admission is deliberately limited.** Refuse unequal source-weld position or normal ownership rather than averaging across a hard edge. Reject nonfinite components; zero/degenerate triangle area or geometric-normal sums; reference-facing reversals; and `dot(g0,g1) <= 0`, which also rejects opposite or poorly conditioned half-turn transport. There is no invented fallback axis. This hemisphere condition is a conservative domain restriction for this small local primitive, not a claim that every larger rotation is physically invalid. The actual source endpoints lie well inside it: minimum affected-face reference cosines 0.9365629 / 0.9616781; maximum geometric-normal rotations 14.3422158° / 8.2860478°.

A normal affected by an unchanged geometric sum should retain its authored bytes, not pass through gratuitous quaternion rounding. The operator reports exact changed POSITION and NORMAL slot sets, maximum rotations, area minima and nonselected preservation.

## Alternatives

- **Replace with local area-weighted normals.** Straightforward, but loses the measured authored offset even on the original mesh unless zero is special-cased; it can create a visible shading boundary at the neighborhood edge. Do not use it as the default policy.
- **Add a geometric-normal difference and renormalize.** Can preserve an explicit zero bypass, but does not preserve the authored offset angle or length. It is not equivalent to a rotation. A hand-solvable fixture will distinguish it from the selected policy.

A whole-body `computeVertexNormals()` call is outside scope because it changes unrelated shading and can change seam handling.

## Proposed bounded operator and byte contract

`createTipWidthOperator({bodyBytes, mapBytes, catalogueBytes, noseBytes})` will first verify explicit current source hashes, copy admitted bytes into private pristine storage, and validate the expected body POSITION/NORMAL/index accessor layout and source mapping. It will expose `candidate(weight)` for **−1/0/+1 only**. The return contains in-memory candidate GLB bytes and a numerical receipt; no file is exported and no original buffer is mutated.

The candidate GLB's only permitted byte changes are float32 components in the body's existing POSITION and NORMAL accessors. This makes every other primitive attribute, every POSITION morph, topology, skin/joints, proxies, hide/decency masks, materials, embedded images and JSON metadata exactly checkable. The zero candidate is byte-identical. Returned arrays cannot become the next pristine source. Changed inputs, unsupported endpoints, accessor aliasing and unsupported layout fail admission.

The underlying small normal-transport kernel may be exercised on analytical geometry fixtures. It is evidence-local, not a generic identity subsystem. The source-owned wrapper is the only route that claims to produce this named candidate.

## Geometry gate

Check all affected triangles at pristine and final Float32 positions for finiteness, non-degenerate altitude and positive reference-facing dot. Reuse the existing source-bound triangle-intersection predicate's 1e-9 metre tolerance; that is a numerical contact tolerance, not a proposed clearance margin. Reject rather than silently prune degenerate inputs. Record the pristine result as well as endpoints.

For self-intersection, compare every affected triangle with all body triangles whose actual bounds overlap. Do not blanket-skip shared-vertex or shared-edge pairs: a folded neighboring pair can overlap beyond its shared boundary. Only an intersection wholly contained in the **exact shared source-index simplex** is ordinary attachment. Any additional contact/coplanar overlap is a witness. Analytical tests must include a folded adjacent pair, nonadjacent crossing, clean shared edge, clean shared vertex and disjoint triangles. If numerical tolerance cannot distinguish an adjacency witness, retain it as unresolved and stop; do not loosen tolerance to pass the source endpoints.

This is a static discrete endpoint test. It does not establish all intermediate weights, all expressions or positive clearance. The actual eye/lid/mouth checks and native views remain separate gates.

## Focused independent controls before native work

- An analytically tilted plane with an authored normal offset: expected rotation and preserved offset/length; expose the additive-difference alternative.
- A changed face whose neighbor is unchanged: include its **complete** star in the normal sum; detect a truncated-neighborhood implementation.
- A UV split with the same source position and normal: outputs stay equal; conflicting hard normals or mismatched weld positions are rejected before output mutation.
- Zero weight exact bytes; separate repeated −1/+1 calls reproduce themselves and cannot mutate the pristine source, prior outputs or caller input.
- Nonfinite inputs, collapsed face, cancelling normal sum, antiparallel geometric normals, reflection/reversal, wrong source hashes, unsupported endpoint/layout and an out-of-allowlist byte corruption are meaningful negatives.
- Actual −1/0/+1 body bytes: source identity, supported delta, local normal ownership, geometry gates and complete nonselected-byte equality. No native, aesthetic, overall identity-coherence or rendered-material verdict follows from these CPU checks.
