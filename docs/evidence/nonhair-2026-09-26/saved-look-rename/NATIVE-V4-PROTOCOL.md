# Rename UI v4: functional evidence and transport admission

This is the next full UI run, not another transport-only retry. Product and built files stay unchanged. `native-probe-v4.mjs` retains the existing nine functional groups, 64 zero-delta warm draws and eight attention steps per owner; no extra settling was added.

Each fresh owner is registered immediately, then the reviewed Blob creation and transport observers finish and restore exact descriptors before warmup or UI. The new read-only classifier requires the exact six native application-consumed GLB hashes. Source and bundle pins distinguish four FileLoader streams (body, bra, briefs, groom) from the two direct styled-fragment paths (outfit, shoes). Every FileLoader group must have one final done witness and exact complete byte total. Group association by unique byte total and clock interval is explicit; parser forwarding is source-derived rather than independently hooked.

There are separate result fields:

- `functionalChecksCompleted`: all nine UI/owner/retirement groups complete with source, runtime and observer guards intact.
- `transportAdmitted`: all original HTTP and Blob response accounting, exact parent provenance and terminal/body records complete with zero raw errors.
- `completed`: both conditions. Only this creates an acceptance seal and exit status 0.

A natural request failure or direct CDP body retrieval error is retained and still rejects strict transport admission. If the owner is ready and native consumed bytes and invariants pass, the controller proceeds with independent UI collection. Runtime console/page errors, server errors, unexpected CDP lifecycle events, source-byte mismatches, unknown response metadata, observer/restoration errors and ownership failures stop functional work. Nonempty mismatching Blob bytes remain fatal. An empty original CDP Blob return stays explicitly separate from exact supplied-Blob provenance.

After closing the context/browser/server, pending body work drains again and every original request ledger plus all Blob/parent admission is rechecked. A late failure cannot yield overall completion. Previously rejected reports, controller bytes and callsite error remain retained. This run does not claim to explain the intermittent transport abort, and it does not qualify live cadence, fit, appearance, hair or arbitrary settings.
