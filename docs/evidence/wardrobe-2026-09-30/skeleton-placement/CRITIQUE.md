## Actionable source findings, resolved before execution

### Silent default-position fallback

Actual example: `mpfb/entities/rig.py` lines 298–299 returns `default_position` if a strategy cannot resolve. Counting outputs alone would not prove placement from the expected helpers.

- **Chosen:** require all referenced native groups to exist and be nonempty, validate MEAN indices, and require every `use_default=False` lookup to resolve. This gives direct admission evidence with little instrumentation.
- **Alternative:** add a read-only observer and assert zero fallback events during placement. This follows execution more closely but adds observer code.

### Rig dispatch admission

Actual example: the first draft of `skeleton-native-oracle.py` admitted the armature using its count of 53 bones before calling public refit. Count alone does not identify a particular rig; no wrong dispatch was observed.

- **Chosen:** require the exact bone-name set and `RigService.identify_rig(rig) == 'game_engine'` before refit. Simple for this fixed table.
- **Alternative:** record the rig-file path actually dispatched by native refit. This adds execution provenance and observer machinery.

### Coordinate-space contract

The declared comparison requires named rest-local endpoints. Native object/pose transformations could otherwise make matching numbers mean different locations.

- **Chosen:** require identity body/armature matrices and every pose basis, then compare directly in Blender Z-up metres.
- **Alternative:** explicitly convert every observation into a common world frame. This supports more fixture transforms but adds conversion complexity now.

The actual six cases pass these admissions. They also preserve the native upgraded legacy table, actual edit rolls, parents and rest matrices.
