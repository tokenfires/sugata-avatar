## Scope and next gate

This is an arithmetic and helper-data oracle, not an appearance candidate. It creates no production GLB, rig, garment corrective, foundation or default. It cannot establish actual fit, motion, wider-body support or representative starter builds. If the comparison succeeds, the next stage still requires explicit corrective behavior, skeleton/foundation coupling and actual rendered/native fit evidence. If it fails, identify the first concrete source or coordinate disagreement before considering a successor. Independent critique must preserve actual witnesses and two alternatives for each actionable issue.
