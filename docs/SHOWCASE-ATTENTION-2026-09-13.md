## Behavior

Changing framing, angle, orbit, outfit or colour palette releases the old sampled view immediately. Release alone retains the action's gentle return. Requests from an unsupported rear view have their own recoverable message, leaving the rest of the lookbook usable. Reduced-motion preference starts the page paused; attention becomes available after an explicit resume. Pausing clears the action. Manual capture stepping now respects the same pause state as live playback; the previous helper incorrectly advanced a paused page.

PNG export retains the existing direct draw and frozen page clock. It does not call the pause handler that would cancel attention. During encoding, attention controls and manual stepping are unavailable. Settings export preserves active motion state but saves configuration only. Page retirement cancels and disposes the action before disposing the Avatar.

A close, angled portrait can reach the existing eye movement bounds. A post-orbit outfit-change check records both upward weights at 0.85 and model residuals of about 1.17/1.27 degrees. The action remains held and uses the declared, bounded eye outputs. This is supported limited correction, not a guarantee of exact contact from every view. Broader perceptual eye-contact qualification remains open.
